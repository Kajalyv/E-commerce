# 🛒 E-Commerce Web Application

A full-stack E-Commerce web application where users can browse products, add items to cart, and place orders securely.

---

## 🚀 Features

- 🔐 User Authentication (Login / Register)
- 🛍️ Browse Products
- 🛒 Add to Cart
- 💳 Checkout System
- 📦 Order Management
- 🛠️ Admin Panel (Optional)
- 📱 Responsive Design

---

## 🏗️ Tech Stack

### Frontend
- React.js
- Axios
- CSS 

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
